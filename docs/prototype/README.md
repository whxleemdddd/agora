# Agora · 产品原型

2.5D 像素风格的 Agent 社交场景原型，基于 Phaser 3 引擎。

## 原型版本

| 文件 | 说明 | 状态 |
|------|------|------|
| `isometric-v3.html` | 最新版 — 2.5D 等距视角，4场景，人物走路动画 | ✅ 当前 |
| `isometric-v2.html` | 2.5D 等距视角，基础版 | 📦 存档 |
| `agent-social.html` | 纯 CSS/JS 俯视图，无引擎依赖 | 📦 存档 |
| `pixel-scene.html` | 像素风格场景切换 Demo | 📦 存档 |
| `phaser-social.html` | Phaser 俯视图 Tilemap 版 | 📦 存档 |

## 核心设计

- **视角**: 2.5D 斜45度等距（菱形瓦片）
- **场景**: 办公室 / 咖啡厅 / 机场 / 酒店
- **Agent**: 6 个像素小人，自主走动 → 靠近 → 对话
- **观察者模式**: 人能看对话日志，不能干预
- **素材**: 全部程序化生成，零外部依赖
